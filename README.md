# ☕ Java DSA

A collection of **Data Structures and Algorithms (DSA)** implementations and problem-solving programs written in **Java**.

This repository contains my practice and implementations of fundamental DSA concepts, searching and sorting algorithms, array problems, and other problem-solving techniques.

---

## 📚 Topics Covered

### 🔹 Arrays
- Array traversal
- Searching in arrays
- Rotated arrays
- 2D arrays / matrices
- Prefix sum
- Kadane's Algorithm
- Array manipulation
- Duplicate and missing element problems

### 🔹 Searching
- Linear Search
- Binary Search
- Order-Agnostic Binary Search
- Floor and Ceiling
- Searching in Infinite Arrays
- Searching in Sorted 2D Arrays
- Rotation Count

### 🔹 Sorting
- Bubble Sort
- Selection Sort
- Insertion Sort
- Counting Sort
- Merge Sort

### 🔹 Array & Matrix Problems
- Maximum and minimum elements
- Rotate array
- Set Matrix Zeroes
- Search in 2D matrix
- Row/Column sorted matrix
- Zig-Zag traversal
- Anti-diagonal traversal
- Buy and Sell Stock problems

### 🔹 Other Problems
- Even digit problems
- Maximum wealth
- Duplicate elements
- Missing and repeated elements
- Array manipulation and transformations
